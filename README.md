# Transcritor Whisper

Envie um vídeo MP4 ou arquivo de áudio e obtenha a transcrição completa em texto, usando Whisper (faster-whisper) em CPU.

Suporta MP4, MP3, WAV, M4A e outros formatos (via ffmpeg).
