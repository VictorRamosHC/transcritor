# 🎙️ Transcritor

[![HTML](https://img.shields.io/badge/HTML-5-orange?logo=html5)](https://html.spec.whatwg.org)
[![CSS](https://img.shields.io/badge/CSS-4-purple?logo=css3)](https://css.spec.whatwg.org)
[![JavaScript](https://img.shields.io/badge/JS-2025-f7df1e?logo=javascript)](https://developer.mozilla.org/js)

> Aplicação web de transcrição de áudio com interface limpa e foco em usabilidade.

---

## ✨ O que faz

Converte arquivos de áudio em texto automático, ideal para:
- Aulas gravadas
- Reuniões
- Interviews
- Materiais de estudo

---

## 🔧 Stack

| Camada | Tecnologia |
|--------|------------|
| **Frontend** | HTML5 + CSS3 + JavaScript (Vanilla) |
| **Upload** | File API + Drag & Drop |
| **Estilo** | Tema escuro, layout responsivo |

---

## 🚀 Como usar

\`\`\`bash
npm install
npm run dev   # ou abra index.html direto
\`\`\`

Abra `http://localhost:3000` e arraste seu áudio.

---

\`\`\`
transcritor/
